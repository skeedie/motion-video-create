# Lyric Studio

Редактор lyric-роликов в стиле iOS-интерфейсов: трек + текст → слова сами встают в такт, каждая строка живёт внутри виджета (чат, справка, счётчик, бомба, крит-урон…), 11 пресетов стиля, экспорт в MP4.

## Скачать
Раздел **Releases** справа → последняя сборка:
- `LyricStudio-Setup-…exe` — установщик;
- `LyricStudio-Portable-…exe` — без установки, просто запустить.

Windows покажет «Неизвестный издатель» — программа не подписана сертификатом: «Подробнее» → «Выполнить в любом случае».

## Как сделать ролик
1. **Трек и текст:** «Выбрать файл…», вставить текст (одна строка = одна строка на экране). Латиницу и цифры можно подсказать в фигурных скобках: `love{лав}`, `1:0{одинноль}`. Если текст звучит в середине длинного трека — укажите, где искать (секунды «с — до»).
2. **«Синхронизировать слова».** В первый раз скачается модель (~240 МБ, один раз). Сцены создадутся сами (по 2 строки — можно выбрать 1 или 3).
3. **Сцена:** кликните сцену внизу → «Шаблон: сменить…» → выберите миниатюру. Поля шаблона (имена, эмодзи, числа, цвета) правятся справа, строка песни встаёт в шаблон сама. Акценты: подпрыгивание на слове, штамп, частицы-эмодзи, размер карточки. Сцены можно объединять и делить.
4. **Стиль:** пресет, формат, отрезок, артист на плашке, вотермарка, частицы, пульс под бит, цвет дыма. Свой стиль можно сохранить как пресет.
5. **Слова:** если слово появляется не в такт — сдвиньте его кнопками ±.
6. **Экспорт в MP4:** 720p (быстро) или 1080p. Пробел — пауза/воспроизведение.

Проект сохраняется в файл `.lsp` (трек хранится по пути, сам файл трека не копируется).

## Разработка
`npm install`, `npm start`. Сборка `.exe` — автоматически в GitHub Actions при каждом пуше в `main`.
