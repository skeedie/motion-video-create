# Lyric Studio

Редактор lyric-роликов в стиле интерфейсов: трек + текст → слова сами встают в такт, каждая строка живёт внутри виджета (чат, справка, комментарии, пост, сторис, бомба, крит-урон…) или крупной типографикой. 11 пресетов, конструктор своего стиля, эффекты, экспорт в MP4 / MOV с прозрачным фоном.

## Скачать
Раздел **Releases** справа → последняя сборка:
- `LyricStudio-Setup-…exe` — установщик;
- `LyricStudio-Portable-…exe` — без установки, просто запустить.

Windows покажет «Неизвестный издатель» — программа не подписана сертификатом: «Подробнее» → «Выполнить в любом случае».

Начиная с 0.2 программа сама находит новые версии и предлагает обновиться (меню «?» → «Проверить обновления»).

## Как сделать ролик
1. **Трек и текст:** «Выбрать файл…», вставить текст (одна строка = одна строка на экране). Латиницу и цифры можно подсказать в фигурных скобках: `love{лав}`, `1:0{одинноль}`. Если текст звучит в середине длинного трека — укажите, где искать (секунды «с — до»).
2. **Нет текста под рукой?** «Распознать с трека» — нейросеть сама расслышит слова, разобьёт их на строки по ритму и сразу расставит по времени. Сленг и имена она путает: поправьте текст и нажмите «Синхронизировать слова». Темп (BPM) определяется сам; если ошибся — ÷2 / ×2, впишите свой или простучите. «Появление слов: подтягивать к 1/16 бита» — слово появляется ровно в долю, сдвиг не больше 60 мс.
3. **«Синхронизировать слова».** В первый раз скачается модель (~230 МБ, один раз). Язык — русский или English (английская модель ~120 МБ), по тексту он выбирается сам. Галочка «сначала отделить вокал» убирает бит нейросетью UVR перед синхронизацией — точнее на громком минусе, но дольше. Сцены создадутся сами: шаблон подбирается по словам строки («звонит» → звонок, «болит» → справка), повторы припева получают одинаковый вид. Слова в скобках — адлибы, они всплывают плашками.
4. **Таймлайн** под превью: волна трека и биты. Слова тянутся мышкой (прилипают к битам, Alt — без магнита, Shift — вся строка), границы сцен тоже. Ctrl+колесо — масштаб.
5. **Сцена:** клик по сцене → «Шаблон: сменить…» (46 шаблонов в 10 разделах). Поля шаблона правятся справа, в аватарки и обложки можно поставить свои картинки. Ctrl/Shift+клик выделяет несколько сцен, Ctrl+C / Ctrl+V переносит вид сцены, настроенную сцену можно сохранить в «Мои шаблоны». Повторы припева меняются вместе.
6. **Стиль:** пресет, формат, отрезок, артист, вотермарка (текст и/или логотип), свой фон — фото или видео с размытием, интро с названием трека и аутро с призывом. «Конструктор стиля» — своя основа, фон, шрифт (можно загрузить свой .ttf), акцент, переход. Пресеты сохраняются, удаляются и передаются файлом `.lspreset`.
7. **Эффекты:** зерно, VHS, хроматическая аберрация, тряска камеры на бит.
8. **Обрезка и звук:** после синхронизации ролик сам обрезается по тактам — начало на сильной доле за такт до первой строки, конец после последней; проигрыши без текста длиннее заданного вырезаются, склейки попадают в такт. Нарастание в начале и затухание в конце настраиваются (длина и кривая), видео может затемняться вместе со звуком. Сцены могут меняться точно на сильную долю.
9. **Экспорт:** MP4 / MOV (ProRes 4444) / WebM с прозрачным фоном / GIF / видеостикер Telegram, 720p–4K, 30 или 60 кадров/с, черновик для быстрой проверки, готовые настройки и безопасные зоны для Reels, TikTok и Shorts. Кадры рендерятся параллельно в нескольких окнах. Очередь сохраняет сразу несколько версий (например 9:16, 1:1 и 16:9) в папку. Отдельно — текущий кадр в PNG и обложка в трёх вариантах (крупное название, типографика, карточка плеера).

**Ещё:** «Профиль» — ник, аватарка, логотип и цвет подставляются во все шаблоны. «Лучший кусок 15/30/60 с» сам выбирает самый энергичный отрывок. «Авто-акценты» ставят подпрыгивание на сильную долю и эмодзи по смыслу, двойной клик по слову на таймлайне — свой акцент (цвет, увеличение, тряска, эмодзи). У каждой сцены может быть свой переход и движение камеры. Текст-крючок сверху на первые секунды. Эффекты могут усиливаться на припеве и дропе. Звуковые эффекты (дзынь, клики, вжух, звонок, удары) синтезируются программой и сводятся с треком. «Сохранить ▾ → вместе с треком (.lspz)» — один файл, чтобы переслать проект. «Новый ▾ → в стиле текущего». «Новый ▾ → Пакет треков» — несколько треков (с текстом или без — тогда он распознаётся) сами проходят синхронизацию, обрезку, сцены, акценты и экспорт. Карточки и стикеры двигаются мышкой прямо в превью (колесо — размер); стикеры и надписи появляются в нужный момент; в сцене может быть две карточки; «Свой виджет из блоков» собирается из шапки, текста, пузырей, счётчика, кнопок; цвета стиля берутся с обложки трека; 3D-наклон карточек. Экспорт MP4 может кодироваться видеокартой (NVIDIA, Intel, AMD), «лёгкое превью» — для слабых компьютеров.

Ctrl+Z / Ctrl+Y — отмена и повтор, Ctrl+S — сохранить, «?» — все горячие клавиши. Проект сохраняется в `.lsp` (картинки и шрифты внутри, трек — по пути); несохранённая работа восстанавливается после закрытия или сбоя.

Если что-то сломалось: меню «?» → «Проверка системы» (проверяет ffmpeg, кодеки, видеокарту, нейросеть, модели, делает пробный экспорт) или «Скопировать отчёт об ошибке» — и вставьте результат в сообщение. Если программа закрылась аварийно, при следующем запуске она предложит восстановить проект и отправить отчёт.

Интерфейс на английском: меню «?» → «English interface».

## Разработка
`npm install`, `npm start`. Проверка интерфейса в браузере без Electron: `python3 dev/server.py` и открыть `http://127.0.0.1:8765/index.html`. Сборка `.exe` — автоматически в GitHub Actions при каждом пуше в `main`.

Модели: русская синхронизация — GigaAM-v2 CTC (MIT), английская — wav2vec2-base-960h (Apache-2.0), отделение вокала — UVR MDX-Net Kim Vocal 2 (скачивается из репозитория UVR при первом использовании).
