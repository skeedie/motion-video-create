# Lyric Studio

Редактор lyric-роликов в стиле интерфейсов: трек + текст → слова сами встают в такт, каждая строка живёт внутри виджета (чат, справка, комментарии, пост, сторис, бомба, крит-урон…) или крупной типографикой. 11 пресетов, конструктор своего стиля, эффекты, экспорт в MP4 / MOV с прозрачным фоном.

## Скачать
Раздел **Releases** справа → последняя сборка:
- `LyricStudio-Setup-…exe` — установщик;
- `LyricStudio-Portable-…exe` — без установки, просто запустить.

Windows покажет «Неизвестный издатель» — программа не подписана сертификатом: «Подробнее» → «Выполнить в любом случае».

Начиная с 0.2 программа сама находит новые версии и предлагает обновиться (меню «?» → «Проверить обновления»).

## Как сделать ролик
1. **Трек и текст:** «Выбрать файл…», вставить текст (одна строка = одна строка на экране). Латиницу и цифры можно подсказать в фигурных скобках: `love{лав}`, `1:0{одинноль}`. Если текст звучит в середине длинного трека — укажите, где искать (секунды «с — до»).
2. **«Синхронизировать слова».** В первый раз скачается модель (~230 МБ, один раз). Язык — русский или English (английская модель ~120 МБ). Галочка «сначала отделить вокал» убирает бит нейросетью UVR перед синхронизацией — точнее на громком минусе, но дольше. Сцены создадутся сами: шаблон подбирается по словам строки («звонит» → звонок, «болит» → справка), повторы припева получают одинаковый вид. Слова в скобках — адлибы, они всплывают плашками.
3. **Таймлайн** под превью: волна трека и биты. Слова тянутся мышкой (прилипают к битам, Alt — без магнита, Shift — вся строка), границы сцен тоже. Ctrl+колесо — масштаб.
4. **Сцена:** клик по сцене → «Шаблон: сменить…» (45 шаблонов в 9 разделах). Поля шаблона правятся справа, в аватарки и обложки можно поставить свои картинки. Ctrl/Shift+клик выделяет несколько сцен, Ctrl+C / Ctrl+V переносит вид сцены, настроенную сцену можно сохранить в «Мои шаблоны». Повторы припева меняются вместе.
5. **Стиль:** пресет, формат, отрезок, артист, вотермарка (текст и/или логотип), свой фон — фото или видео с размытием, интро с названием трека и аутро с призывом. «Конструктор стиля» — своя основа, фон, шрифт (можно загрузить свой .ttf), акцент, переход. Пресеты сохраняются, удаляются и передаются файлом `.lspreset`.
6. **Эффекты:** зерно, VHS, хроматическая аберрация, тряска камеры на бит.
7. **Экспорт:** MP4 / MOV (ProRes 4444) / WebM с прозрачным фоном / GIF, 720p–4K, 30 или 60 кадров/с, черновик для быстрой проверки, готовые настройки и безопасные зоны для Reels, TikTok и Shorts. Кадры рендерятся параллельно в нескольких окнах. Очередь сохраняет сразу несколько версий (например 9:16, 1:1 и 16:9) в папку. Отдельно — текущий кадр и обложка в PNG.

Ctrl+Z / Ctrl+Y — отмена и повтор, Ctrl+S — сохранить, «?» — все горячие клавиши. Проект сохраняется в `.lsp` (картинки и шрифты внутри, трек — по пути); несохранённая работа восстанавливается после закрытия или сбоя.

Если что-то сломалось: меню «?» → «Скопировать отчёт об ошибке» и вставьте его в сообщение.

## Разработка
`npm install`, `npm start`. Проверка интерфейса в браузере без Electron: `python3 dev/server.py` и открыть `http://127.0.0.1:8765/index.html`. Сборка `.exe` — автоматически в GitHub Actions при каждом пуше в `main`.

Модели: русская синхронизация — GigaAM-v2 CTC (MIT), английская — wav2vec2-base-960h (Apache-2.0), отделение вокала — UVR MDX-Net Kim Vocal 2 (скачивается из репозитория UVR при первом использовании).
